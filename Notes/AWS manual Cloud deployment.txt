23. The "Magic" Step: AWS Security Groups
By default, AWS blocks everyone. Even if your app is running, the "door" (port) to the outside world is locked.

Go to the AWS EC2 Console.

Click on Instances and select yours.

Click the Security tab below.

Click on the Security Group link (e.g., sg-0a1b2c3d...).

Click Edit inbound rules.

Add this rule:

Type: Custom TCP

Port Range: 8085

Source: 0.0.0.0/0 (This means "The whole internet")

Click Save rules.

24. Your live link is your Public IPv4 DNS combined with your port. You can find this in your EC2 instance summary. It will look like this:
